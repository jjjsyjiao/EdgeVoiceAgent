# 报告边界

`synthetic-contract-metadata-v1.json` 与对应 `.ranked.jsonl` 来自仓库手写的 **synthetic_contract** 元数据样例：9 条记录、8 个事件、16 条问题；其中 11 条标注可回答、4 条已知无答案、1 条覆盖未知。

当前规则基线 Candidate Hit@50 为 9/11。遗漏的同义词与只存在于画面中的线索是有意设置的契约用例。这个比例不是产品召回率，不衡量图文向量、重排、真实生活场景或实际模型回答。所有数字只用于检测评测代码或规则基线是否发生变化。

完整报告包含 Wilson 区间、事件级 Recall、分组统计、数据/评分函数 fingerprint、违规列表和每问的候选。真实数据报告只应在私有评测目录生成；未经复核不要把真实媒体或个人问题提交到本目录。
