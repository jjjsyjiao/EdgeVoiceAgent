# `EdgeVoiceAgent-SDK` 架构设计文档 (V3.0 - UI 与全链路双模架构版)

* **文档版本：** V3.0.0
* **架构定位：** 一款面向端侧/跨平台多媒体实时交互的、**高内聚、低耦合、模块化、完全可插拔**的 Agent 客户端工程架构。支持“云端大模型 Agent（Cloud-based）”**与**“本地端侧小模型 Agent（On-Device Local）”的双模自由热切换，并拥有现代化的 **Jetpack Compose 沉浸式 UI 状态驱动层**。
* **设计原则：** 响应式驱动、接口隔离、依赖倒置（DI）、策略模式（Strategy Pattern）、零拷贝（Zero-Copy）性能优化、软硬分离。

---

## 一、 整体架构分层设计（Layered Architecture）

整个 SDK 采用严格的**五层单向依赖架构**（上层依赖下层，下层对上层无感知），确保精美的 UI 交互与底层的多媒体流处理、网络传输及模型执行彻底解耦。

```
+---------------------------------------------------------------------------------+
|                              1. UI & Presentation Layer                         |
|      (Jetpack Compose M3 / Dynamic Orb Visualizer / Developer Debug Drawer)     |
+---------------------------------------------------------------------------------+
                                         |
                                         v (StateFlow 响应式驱动)
+---------------------------------------------------------------------------------+
|                                2. SDK Core Layer                                |
|        (Agent Orchestration Engine / State Machine / Context Fusion)            |
+---------------------------------------------------------------------------------+
         |                                       |                        |
         v                                       v                        v
+-----------------+                     +-----------------+      +-----------------+
| 3. Media Layer  |                     | 4. Transport    |      | 5. Executor     |
| (AudioRecord /  |                     | (WebSocket /    |      | Strategy Layer  |
|  CameraX /      |                     |  WebRTC /       |      | (Cloud / Local  |
|  Ring Buffer)   |                     |  Network IO)    |      |  Execution)     |
+-----------------+                     +-----------------+      +-----------------+
         |                                       |                        |
         +---------------------------------------+------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
|                             6. Hardware Abstraction                             |
|         (NPU/APU Accelerator, Bluetooth Audio, Camera ISP, Native NDK)          |
+---------------------------------------------------------------------------------+

```

## 二、 核心模块划分与职责定义（Modular Design）

### 2.1 模块一：`ui-presentation`（UI 表现与状态驱动层 —— **新增**）

* **职责：** 负责构建现代化的 AI 交互视界，通过 Jetpack Compose 实现沉浸式体验。
* **核心组件：**
* **Dynamic Orb Visualizer：** 动态灵动球与声波核心区，根据 SDK 的状态机变化实时渲染光效、渐变和音频振幅跳动。
* **Multimodal Camera Overlay：** 半透明多媒体视觉与抽帧预览窗口。
* **Developer Debug Drawer：** 实时监控底层网络延迟（RTT）、缓冲区占用率以及云端/本地模式一键切换的调试抽屉。


* **解耦设计：** UI 层不包含任何业务逻辑或硬件调用，完全通过 **Kotlin StateFlow** 响应式订阅 SDK 核心层的状态流（Zero-Touch Hardware/Network Binding）。

### 2.2 模块二：`sdk-core`（Agent 编排与状态机模块）

* **职责：** 维护对话生命周期、状态流转（`IDLE_OBSERVING` -> `LISTENING` -> `PROCESSING` -> `SPEAKING` -> `INTERRUPTED`）及多媒体上下文融合。
* **解耦设计：** 作为整个 SDK 的大脑，通过依赖注入动态装配底层多媒体、传输通道及模型执行器。

### 2.3 模块三：`core-media`（多媒体与流处理模块）

* **职责：** 负责音频采集（AudioRecord）、视频抽帧（CameraX）、环形缓冲区（Ring Buffer）与抖动缓冲区（Jitter Buffer）的管理。
* **解耦设计：** 采用 Ring Buffer 隔离采集与发送线程，彻底消除高并发下的内存抖动。

### 2.4 模块四：`core-transport`（全双工传输通道模块）

* **职责：** 负责云端模式下的网络长连接维持、重连及弱网对抗。
* **核心契约：** `ITransportClient`（支持 WebSocket 与 WebRTC 的可插拔实现）。

### 2.5 模块五：`core-executor`（双模代理执行策略层）

* **职责：** 定义统一的 Agent 执行器契约（`IAgentExecutor`），实现**云端大模型与本地端侧小模型的自由热切换**。
* **两大策略实现：**
* `CloudRealtimeExecutor`：封装 WebSocket 对接云端 Realtime API。
* `OnDeviceLocalExecutor`：集成 MediaPipe / MLC-LLM 在本地 NPU 运行轻量化端侧 SLM。



### 2.6 模块六：`hardware-bridge`（硬件适配层）

* **职责：** 适配手机伴侣模式（Companion Mode）与独立硬件模式（Standalone Mode），对硬件麦克风、相机及 NPU 加速芯片进行统一抽象。

## 三、 全链路响应与交互时序（以用户打断为例）

```text
[Hardware/Mic] ---> [core-media (RingBuffer)]
                           |
                           v (检测到人声/打断指令)
             [sdk-core (State Machine -> INTERRUPTED)]
              |                                       |
              v (StateFlow 状态下发)                   v (异步协同)
     [ui-presentation]                      +---------+---------+
 (Dynamic Orb 瞬间闪烁并清空播放动效)         |                   |
                                             v                   v
                                    [core-transport]    [core-media]
                                    (发送 Interrupt)    (清空 AudioTrack 队列)

```

## 四、 架构优势总结（大厂面试核心亮点）

1. **表现层与底层彻底分离：** 采用单向数据流（MVI/MVVM + StateFlow），UI 仅作为状态的投影，确保了极端网络或高并发多媒体流转时 UI 线程的绝对丝滑（60/120 FPS）。
2. **双模热切换与软硬解耦：** 兼具云端大模型的强大算力与本地端侧 SLM 的隐私离线优势，适应全场景落地。
3. **极高的工程成熟度：** 从底层 NDK 缓冲区优化、全双工 WebSocket/WebRTC 传输，到上层现代 Compose 灵动视界，展现了全栈高级工程师的架构把控力。
